# typora-next 功能设计文档

**日期**: 2026-05-03
**状态**: 已确认

---

## 1. 核心定位

**产品定位**: Markdown 预览器（重预览、轻编辑）

**目标用户**: 技术文档撰写者——API 文档、教程、README、开发笔记

**核心价值**:
- 渲染质量超越 Typora（数学公式、图表、代码块）
- 项目级文档管理（多文件、目录导航）
- 高质量导出（PDF、精美 Word）

**使用场景**: 用户在编辑器（VS Code / Obsidian）中写 Markdown，同时打开本预览器查看渲染效果。切换到预览器做高质量导出交付。

---

## 2. 渲染增强

### 代码块增强
- 行号显示（左侧固定列）
- 文件名标注（代码块顶部显示来源文件）
- 一键复制按钮（点击复制整段代码）
- 精美高亮样式（基于 Prism.js，自定义主题）

### 数学公式渲染
- KaTeX 渲染（比 MathJax 快 10x）
- 行内公式 `$x^2$` → 实时渲染
- 块级公式 `$$...$$` → 居中显示

### 图表支持
- Mermaid：流程图、时序图、甘特图、类图
- 渲染为 SVG，可点击放大查看

### 图片处理
- 本地相对路径图片 `![](./img.png)`
- 网络图片 `![](https://...)`
- 点击放大查看，支持缩放操作

---

## 3. 文档管理

### 项目模式
- 打开文件夹，侧边栏显示文件树结构
- 支持目录展开/折叠
- 搜索过滤：输入关键词快速定位文件
- 点击文件在 Tab 中打开

### 多标签 Tab
- 单窗口内多文件切换
- Tab 显示文件名，可关闭
- Ctrl+Tab 切换标签

### 侧边目录 TOC
- 左侧固定目录树，显示文档标题层级
- 可折叠子章节
- 点击跳转到对应位置
- 当前位置高亮显示

### 源码切换
- 快捷键 Ctrl+E 切换：预览 ↔ 源码模式
- 源码模式：纯文本显示，可做小改动

---

## 4. 导出功能

### PDF 导出
- 保持渲染样式（字体、颜色、排版）
- 图表（Mermaid）导出为嵌入图片
- 页眉页脚可选（文件名、页码、日期）
- 支持页面尺寸配置（A4、Letter 等）

### Word 导出（精美模式）
- 保持预览样式：标题层级、列表、表格
- 代码块：保持高亮颜色，使用 Word 表格样式
- 数学公式：转换为 Word 公式对象或嵌入图片
- 图表（Mermaid）：导出为图片嵌入
- 图片：保持原尺寸比例

### 导出入口
- 菜单：文件 → 导出 → PDF / Word
- 快捷键：Ctrl+Shift+P（PDF）、Ctrl+Shift+W（Word）

## 5. 交互体验

### 文件刷新机制
- 检测外部文件修改（VS Code 等编辑器改动）
- 弹窗提示："文件已更新，是否刷新？"
- 用户确认后重新渲染

### 快捷键（标准 Web 模式）

| 功能 | 快捷键 |
|------|--------|
| 打开文件 | Ctrl+O |
| 打开文件夹 | Ctrl+Shift+O |
| 切换源码 | Ctrl+E |
| 刷新 | Ctrl+R |
| 关闭 Tab | Ctrl+W |
| 切换 Tab | Ctrl+Tab |
| 导出 PDF | Ctrl+Shift+P |
| 导出 Word | Ctrl+Shift+W |
| 切换主题 | Ctrl+Shift+T |
| 退出 | Ctrl+Q |

### 主题系统
- 默认主题：浅色/深色切换
- 自定义主题：CSS 文件配置

## 6. AI 修复 Mermaid

### 触发条件
- Mermaid 图表渲染失败时，显示错误信息
- 错误信息旁显示 "AI 修复" 按钮

### 修复流程
1. 用户点击 "AI 修复" 按钮
2. 调用配置的 AI 模型（API 或本地模型）
3. AI 分析语法错误，返回修复建议
4. 显示修复前后代码对比
5. 用户选择：采纳修复 / 忽略（保留原代码）

### AI 配置
- 设置界面：可选择 API 方案或本地模型
- API 支持：OpenAI / Claude / 其他兼容 API（需用户提供 API Key）
- 本地模型：内置小型语法修复模型（可选）
