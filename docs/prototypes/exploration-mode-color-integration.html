探索模式：让 Tab 颜色与阅读区融为一体的方案

主基调仍是蓝色，探索模式使用青色（Teal）作为区分色——与蓝色相邻、和谐但不冲突。
每个方案都提供浅色 / 深色两种视图，重点是让阅读区也能感受到“探索模式”的氛围。

方案 1：Tab 染色（当前做法）

只有 Tab 变成青色，阅读区保持原样。作为对比基准。

方案 2：强调边框

把青色延伸到阅读区的边框：顶部边线、文章面板左边线、聊天面板顶部分隔线、侧边栏右边线。视觉冲击最小，但立刻让阅读区和 Tab 产生关联。

方案 3：面板淡染色

给文章区和聊天区都加上极淡的青色底色，让用户一进入探索模式就能感知到“整个空间都变了”。用户气泡和发送按钮也改用青色，强化归属。
