第五章 · 位置编码

Transformer 处理序列时是"并行"的——所有 token 一次性进入模型，不像 RNN 那样串行。 但这带来一个问题：模型怎么知道"猫坐垫"和"垫坐猫"的顺序？

答案是 位置编码 。我们给每个 token 加一个位置向量，让"第 0 个位置"和"第 1 个位置"在向量空间里不一样。 Transformer 用正弦余弦生成这些向量。

接下来我们看具体数学形式：PE(pos, 2i) = sin(pos / 10000^(2i/d_model))...

选中 "位置编码"
位置编码给每个 token 加一个位置向量（如 [0.1, 0.3, ...]），让模型能区分序列顺序。Transformer 用正弦余弦实现，无需额外训练参数。
Q: 举个例子
比如"猫坐垫"和"垫坐猫"，位置编码会给"猫"标 0、"坐"标 1、"垫"标 2，让模型知道顺序。
Q: 为啥用正弦？
正弦/余弦能生成周期性模式，模型可学习相对位置（PE(pos+k) 可表示为 PE(pos) 的线性函数），且不需要训练参数。
Q: 代码怎么写？
PyTorch 示例：PE(pos, 2i) = sin(pos / 10000^(2i/d_model))，PE(pos, 2i+1) = cos(...)。
