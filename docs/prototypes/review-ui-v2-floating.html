📋 方案B 状态机与 UX 说明

触发时机：打开 Typora 时右下角滑入 pill（延迟 1.5s，避免启动瞬间打扰）
进入路径： ① app启动 → 检测到期 → 滑入 pill 被动感知
② 用户点击 pill → 展开面板（当前状态）
退出路径： ① 点击"开始复习" → 面板内容替换为复习题 → 完成后自动收起为"已完成"状态； ② 点击"今天先不复习"或 panel-close → 收起为 pill，hover 显示"今日已跳过"； ③ 点击 pill 再次展开 → 可随时重新进入 有重新进入路径
视觉标识：pill 常驻右下角，数字 badge 红色提醒；展开后明确是浮动面板
异常恢复：复习中途关闭应用，记录已答题目，下次从断点继续；跳过后当天不再提醒，次日重置 有恢复
风险评估：不打断工作流，用户完全掌控节奏；但弱提醒可能导致遗忘 提醒强度弱
