探索模式：5 种聊天窗口 UI 方案

入口保持现状（右键/Tab 右键），只优化 AI 对话窗口的呈现方式。
每个方案都可以切换浅色/深色主题预览。

方案 1：当前上下分屏（基准）
文章在上、聊天在下，左侧列出所有对话。占用稳定空间，适合把 AI 对话当作阅读的主要 companion。
