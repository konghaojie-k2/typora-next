📋 方案C 状态机与 UX 说明

触发时机：打开 Typora 时顶部横幅滑入 + 右侧复习侧边栏展开
进入路径： ① app启动 → 检测到期 → 横幅+侧边栏同时出现 沉浸式
② 用户点击横幅"开始复习" → 侧边栏进入复习模式（逐题/逐概念）
退出路径： ① 点击横幅"稍后" → 横幅收起，侧边栏折叠为窄条（显示进度），可点击重新展开； ② 点击横幅 ✕ → 完全关闭横幅，侧边栏保留为可展开状态； ③ 完成所有复习项 → 横幅变为绿色"今日复习完成 ✅"，3 秒后自动收起 明确完成态
视觉标识：顶部横幅常驻 + 右侧边栏可见，用户始终感知复习进度
异常恢复：复习中途关闭应用，quiz-history.json + project.json 记录每项完成状态，下次打开自动恢复进度 有恢复
风险评估：占用编辑区域空间（侧边栏 320px），小屏幕用户可能感到拥挤 空间占用
