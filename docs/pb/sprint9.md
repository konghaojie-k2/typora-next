# Sprint 9 — 探索模式（自由阅读 / AI 对话式深度阅读）

## PB1: 探索面板浮窗

**验收标准**:
- 每个 Markdown 文件独立的浮窗面板
- 面板可拖拽、调整大小、关闭 (Esc)
- 位置/大小持久化到 localStorage（按文件名）
- 文件树/标签页右键菜单"进入探索模式"

**状态**: ✅ 已完成（Round 1-3）

## PB2: 多对话管理

**验收标准**:
- 每个文件支持多个命名对话
- 对话可创建、切换、重命名、删除
- 对话标题从首条用户消息自动生成
- 对话按文件持久化到磁盘 (Tauri) 或 localStorage (Web)

**状态**: ✅ 已完成（Round 1-3）

## PB3: 真实 Agent SDK 调用 ← 当前 Sprint

**验收标准**:
- Tauri 模式下，消息发送后通过 agent-bridge.js 调用 `@anthropic-ai/claude-agent-sdk` 的真实 `query()` 函数
- 等待回复期间显示"AI 思考中..."加载指示器
- 输入框在加载期间禁用，防止重复发送
- Web 预览模式显示友好提示，引导用户使用桌面应用
- Agent SDK 调用失败时显示格式化错误消息，可继续发送下一条消息
- 使用自然、非苏格拉底式的阅读伙伴 prompt

**状态**: 🔄 进行中（Round 2 — 替换 stub 为真实实现）
