# 学习材料 Markdown 结构规范

> 基于 `00-为什么需要-Transformer-从-RNN-到注意力机制.md` 的最终验收结构。

---

## 一、思考题（question）

### 目标效果
- **外层**：`❓ 思考题...` 默认展开，显示题目
- **内层**：`💡 查看答案` 默认折叠，点击展开显示答案
- answer 嵌套在 question 内部，是一个独立的折叠 callout

### Markdown 结构

```markdown
> [!question]
> **思考题**：为什么 RNN...?
>
> > [!answer]- 查看答案
> >
> > 答案内容直接从这里开始，不需要再加"**答案**："标题。
> >
> > 可以有多段、列表、公式等。
```

### 关键规则

| 规则 | 说明 |
|------|------|
| `[!question]` 无 `-`/`+` | 默认展开，显示题目 |
| `[!answer]-` 必须带 `-` | 默认折叠 |
| `查看答案` 用纯文本 | 不要加 `**查看答案**`，渲染层会自动去除 `**`，但纯文本最保险 |
| answer 嵌套在 question 内 | 用 `> >` 两层 blockquote |
| `> > ` 后紧跟空行 | `[!answer]- 查看答案` 和答案内容之间要有空行（`> > `） |
| 答案内容不加"**答案**：" | callout 标题已经是"查看答案"，内容里不要再写"答案"标题 |

### ❌ 错误示例

```markdown
> [!question]
> **思考题**：...
>
> > [!answer]- **查看答案**     <-- 错误：不要加 **
> > **答案**：                  <-- 错误：多余的"答案"标题
> > 内容...
```

### ✅ 正确示例

```markdown
> [!question]
> **思考题**：为什么 RNN 理论上可以通过梯度下降学会"记住"长期信息？
>
> > [!answer]- 查看答案
> >
> > 理论上，RNN 的权重矩阵 $W_{hh}$ 可以被优化到...
> >
> > LSTM 通过"细胞状态"和门控机制...
```

## 二、测验题（quiz）

### 目标效果
- `📝 小测验` 默认展开，显示题目和选项
- `💡 查看答案` 按钮折叠答案（由 Sprint3 代码添加）
- 答案嵌套在 quiz 内部

### Markdown 结构

```markdown
> [!quiz]
> **小测验**
>
> **1. 题目内容？**
>
> **A.** 选项A
>
> **B.** 选项B
>
> **C.** 选项C
>
> **D.** 选项D
>
> > [!answer]- 查看答案
> >
> > **答案：B**
> >
> > - **A 错误**：...
> > - **B 正确**：...
> > - **C 错误**：...
> > - **D 错误**：...
```

### 关键规则

| 规则 | 说明 |
|------|------|
| 选项用 `**A.**` 格式 | 不要用 `- A.` 列表格式，避免 blockquote 边界解析问题 |
| 答案用嵌套 `[!answer]-` | 和 question 一样内嵌在 quiz 内部 |
| 答案里可以写"**答案：B**" | quiz 答案需要标明正确选项，所以保留答案标题 |

## 三、渲染层行为（Sprint3）

### `initObsidianCallouts`（main.js）
- 匹配 `> [!TYPE]` / `> [!TYPE]-` / `> [!TYPE]+`
- `-` 表示默认折叠，无后缀表示默认展开
- title 中的 `**text**` 会被自动去除，显示纯文本

### `enhanceLearningElements`（mode-integration.js）
- 对 **内嵌 answer callout**（在 question/quiz 内部的）直接跳过，不合并
- 让 answer 保持独立的折叠 callout，由 `initObsidianCallouts` 处理

### 图标映射

| Callout 类型 | 图标 | 标题 |
|-------------|------|------|
| `[!question]` | ❓ | Question |
| `[!answer]` | 💡 | Answer |
| `[!quiz]` | 📝 | Quiz |

---

## 四、总结：核心要点

1. **question 展开 + answer 折叠**，answer 嵌套在 question 内部
2. `[!answer]- 查看答案` 用**纯文本**标题，不要加 `**`
3. 答案内容**不要再写"答案"标题**，直接开始正文
4. `[!answer]-` 和正文之间要有一个**空行**（`> > `）
5. quiz 选项用 `**A.**` 格式，不要用列表
