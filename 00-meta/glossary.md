# 术语表

> 项目中的专业术语和缩写，确保所有参与者理解一致。

---

## 技术术语

| 术语 | 说明 |
|------|------|
| Tauri | 跨平台桌面应用框架，Rust 后端 + WebView 前端 |
| WebView | 嵌入在桌面应用中的浏览器引擎 |
| KaTeX | 数学公式渲染库（比 MathJax 快 10 倍） |
| Mermaid | 图表渲染库（流程图、时序图、甘特图） |
| Prism.js | 代码高亮库 |
| Markmap | 思维导图渲染（基于 markdown 列表） |
| pulldown-cmark | Rust 编写的 CommonMark / GFM Markdown 解析器 |
| IPC | Inter-Process Communication，Rust 与 WebView 之间的通信 |

## 项目术语

| 术语 | 说明 |
|------|------|
| Harness | 本项目管理框架，"文件系统即共享记忆" |
| Inbox | `90-inbox/`，待处理输入的存放位置 |
| ADR | Architecture Decision Record，架构决策记录 |
| Thread | 活跃工作项/任务线 |
| Bootstrap | 初始化流程，首次进入项目时执行 |
