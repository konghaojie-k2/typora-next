# 90-inbox / 反馈收件箱

> 这里是用户反馈、需求、想法的投递站。
> 
> **你只管丢进来，Agent 会负责整理。**

---

## 怎么丢？

直接把内容放到这个文件夹下，任何格式都行：

- `bug_xxx.md` — Bug 报告
- `feature_xxx.md` — 功能需求
- `idea_xxx.md` — 想法/建议
- `feedback_xxx.md` — 使用反馈
- `question_xxx.md` — 疑问
- `screenshot_xxx.png` — 截图（配合简短文字说明）
- `meeting_xxx.md` — 会议记录

文件名建议包含日期，如 `bug_20260508_crash_on_open.md`

---

## 丢完会怎样？

1. **Agent 自检时发现** — 每次进入项目，Agent 会自动扫描 inbox
2. **内容摘要** — Agent 会提炼核心内容
3. **初步分类** — bug / feature / idea / question 等
4. **提议归档** — Agent 建议放到哪个目录/线程下
5. **你确认后归档** — 你点头，Agent 就执行归档
